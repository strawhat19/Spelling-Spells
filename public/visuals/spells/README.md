# Midnight Archive — Spell Illustrations

Nine original AI-generated still illustrations created for Spelling Spells on 2026-10-16 using the built-in `image_gen.imagegen` tool. Each scene was generated separately in a cohesive cinematic/painterly style with violet shadows, aged materials and spell-specific light. No CLI/API fallback or external source image was used; Lumos received one focused edit to remove an unwanted corner mark.

All final files are opaque PNG images at **1672 × 941 pixels**, approximately 16:9. They were visually inspected and copied unchanged into this directory; the original generated files were retained. Total PNG size: **23,015,299 bytes** (about 21.95 MiB). Existing assets elsewhere in `public/visuals/` were preserved.
