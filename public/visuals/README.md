# Spelling Spells — Runtime Artwork

`hero-night-background.png` is the illustrated backdrop for the Midnight Archive landing hero. It was generated with the built-in image tool from the approved `assets/concepts/mockups/v1/01-midnight-archive.png` design, removing its interface and typography while preserving the night palette, purple mist, forest, castle silhouette, books, candle, quill, and gold orbital sparks.

Application text, spell cards, navigation, controls, and the exact chosen logo watermark are rendered separately. The background contains no functional interface.

`IMAGEGEN-PROMPTS.md` records the prompt. The original mockup and prior logo rounds are preserved. No third-party franchise logos or character artwork are used.
