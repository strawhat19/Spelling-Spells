# Spelling-Spells — Logo Concepts v2

Created October 6, 2026 as a new review round. The user selected **Letter Spark** from v1 and requested a wand or spellbook, keeping a nighttime purple and yellow/gold mood. This round continues the original A geometry and spark. All v1 files remain unchanged; no identity is adopted.

| Concept | Refinement | Likely use |
| --- | --- | --- |
| 01 · Wand Spark | The original A beside a tilted wand, with a large golden tip spark. | Primary logo, header, avatar |
| 02 · Book Spark | The A rises from an open spellbook; lavender pages meet at a gold fold. | Learning identity, editorial use, app symbol |
| 03 · Wand Letter | The right stroke of the A becomes a golden wand with a purple grip band; the spark sits above the letter. | Compact unified identity, tool icon |

## Palette

- Violet `#6039D8`: carried forward from v1.
- Yellow gold `#FFC857`: carried forward from v1.
- Night ink `#20134D`: wordmarks and single-ink samples.
- Lavender `#D8C8F2`: soft supporting page color.
- Midnight `#17102B`: comparison sheet background only.
- Pale lavender `#F8F4FF`: comparison sheet panels only.

## Files

- `00-concept-sheet.svg` and `00-concept-sheet.png`: editable flat comparison sheet and its raster export.
- `01-wand-spark.svg` / `01-wand-spark-mark.svg`: lockup and standalone mark.
- `02-book-spark.svg` / `02-book-spark-mark.svg`: lockup and standalone mark.
- `03-wand-letter.svg` / `03-wand-letter-mark.svg`: lockup and standalone mark.

Individual SVGs have transparent surrounding canvases, accessible titles/descriptions, and editable original geometry. Text uses Avenir Next with Arial/sans-serif fallbacks; final font choice and outlines remain for adoption. The comparison sheet is artwork for reviewing logos, not an app mockup. SVG sources were authored directly; no raster image generator or third-party icon assets were used.

No application code or implementation assets were changed. Files are saved locally; no tests, builds, app UI checks, commits, or pushes were performed.
