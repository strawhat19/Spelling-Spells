# Spelling-Spells — Close Book Spark v4

Created October 6, 2026. This follows the selected **Angled Wand Tips** from v3. The user asked for the A and book to sit closer, allowed overlap, and requested visible book lettering and scribbles. Both concepts keep the purple A, angled ivory caps, deep-purple grip bands, symmetrical centered gold spark, and lavender open book.

| Concept | Change | Likely use |
| --- | --- | --- |
| 01 · Bound Spellbook | Book rises 18 SVG units. The A's wand tips overlap its upper page edge. | Main identity, header, avatar |
| 02 · Deep Spellbook | Book rises 28 SVG units for a tighter unified silhouette. Lettering stays below the tips. | Compact identity, tool symbol |

The book is drawn behind the A so the ivory tips remain exposed. A/B lettering and short handwritten lines sit lower on the pages. The visible letters use editable Georgia bold italic text with Times New Roman/serif fallbacks; scribbles are original vector paths.
