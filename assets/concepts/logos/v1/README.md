# Spelling-Spells — Logo Concepts v1

First identity exploration, created October 6, 2026. These are reviewable concepts; none is adopted.

The repository currently contains shared AI guidance. The brief is inferred from the name: a spelling tool with a playful language-and-magic theme. These logos do not imply that application features already exist. Exact wordmark: **Spelling-Spells**.

| Concept | Idea | Likely use |
| --- | --- | --- |
| 01 · Letter Spark | A geometric A with an isolated discovery spark. The simplest and most direct learning symbol. | Primary identity, compact avatar, header |
| 02 · Spellbook | An open book and flowing S join education and a light magical theme. | Friendly learning identity, editorial branding |
| 03 · Rune Tiles | Offset tiles and a custom S suggest building words through play. | App/tool icon, playful identity |

## Palette

- Violet `#6039D8`: primary symbol color.
- Amber `#FFC857`: discovery accent.
- Lilac `#E9E2FF`: supporting book page color.
- Ink `#20134D`: wordmarks and monochrome samples.
- Paper `#F6F3FC`: comparison sheet only; individual SVG backgrounds are transparent.

## Files

- `00-concept-sheet.svg`: flat comparison artwork, not a product mockup.
- `00-concept-sheet.png`: raster export of the same comparison artwork for convenient review.
- `01-letter-spark.svg` and `01-letter-spark-mark.svg`: lockup and standalone symbol.
- `02-spellbook.svg` and `02-spellbook-mark.svg`: lockup and standalone symbol.
- `03-rune-tiles.svg` and `03-rune-tiles-mark.svg`: lockup and standalone symbol.

All marks are original authored vector paths/shapes, with editable fills, strokes, and groups. SVGs include accessible titles and descriptions. Wordmark text is editable and uses Avenir Next with Arial/sans-serif fallbacks; its appearance depends on installed fonts. Final font selection, outlines, optical refinements, and adoption remain for a later chosen direction. No third-party characters, stock icons, external assets, or raster image generator were used.

App code and implementation assets are untouched. No tests, builds, app UI checks, commits, or pushes were run for this round.
