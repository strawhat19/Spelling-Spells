# Spelling-Spells — Soft Lines v7

Created October 6, 2026. This round directly refines the selected v6 **02 · Leg-Parallel Wands** concept. The original purple A, the two mirrored wands parallel to its legs, ivory magician tips, centered gold spark, close book position, and exact Spelling-Spells wordmark are retained.

The book now uses symmetrical straight page edges and a clean central fold. Rounded outline joins soften the geometric silhouette. Three short rows of page detail are centered within each page, with generous space at the outer edges, top, bottom, and fold. The right page is an exact reflection of the left.

| Concept | Direction | Likely use |
| --- | --- | --- |
| 01 · Soft Spell Notes | Restrained, smooth, symmetrical scribbles at 28% purple opacity, with a fine 1.6-unit stroke. | Friendly main identity, learning app header, avatar |
| 02 · Soft Page Lines | Three straight, centered page rules with the same fine stroke, subtle opacity and rounded ends. | Calmer main identity, compact app icon, header |

## Palette

- Purple: `#6039D8`
- Gold: `#FFC857`
- Lavender pages: `#D8C8F2`
- Ivory tips: `#FFF9EA`
- Night ink: `#20134D`

Page details use the existing purple at 28% opacity over lavender, rather than introducing another saturated color. The review sheet uses midnight `#17102B` and pale lavender `#F8F4FF` presentation backgrounds.

Earlier v1–v6 concepts remain unchanged. This is a local, uncommitted design round. No application code, tests, builds, UI checks, commits, or pushes were performed.
