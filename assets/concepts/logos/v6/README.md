# Spelling-Spells — Spellbook & Wand Concepts v6

Created October 6, 2026. The user requested cleaner centered page marks with edge clearance, two parallel symmetrical wands next to the A's legs, and a version using S with the same wand-tip language.

The selected A geometry, purple/ivory tip treatment, centered spark, and close book position from v5 are retained for the A variants. Page marks are now three short, individually drawn calligraphic paths with consistent rounded strokes. Each left-page block is centered around x=76, narrowed to x=54–98; the right is an exact reflection around the fold at x=128. Shorter rows taper into a contained text block, leaving space at the outer edges, fold, top, and bottom.

| Concept | Idea | Likely use |
| --- | --- | --- |
| 01 · Centered Spellbook | Refines the selected A using only the new centered page marks. | Main identity, header, avatar |
| 02 · Leg-Parallel Wands | Two mirrored wands sit alongside and parallel to the respective A legs. | More explicit magician/learning identity |
| 03 · Parallel Wand Pair | Two upright wands are parallel to each other and mirror-spaced around the A. | Calm framed identity, tool icon |
| 04 · S Spellbook | An original broad purple S replaces A; its endpoints have pale caps and deep-purple bands. | Initial-led spelling identity |

Both wand arrangements are included to show the two useful interpretations of parallel wands beside the A. Each separate wand uses the same purple body and pale end caps. The S is an original editable curved vector stroke, not a font glyph.
