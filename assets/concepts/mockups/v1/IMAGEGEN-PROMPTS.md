# Spelling-Spells — Image Generation Prompts v1

Method: built-in `image_gen.imagegen`, three independent `ui-mockup` requests. No CLI/API fallback was used. Each request uses `selected-logo-reference.png` as a brand reference, with an opaque mockup background. The selected editable logo remains in the adjacent SVG files.

Preserve the complete layout, colors, logo, headline, exact large Lumos card, buttons, backgrounds, stars, wordmark and all typography sizes. On the RIGHT Brisingr card replace the lower explanatory text which mentions Dragon Language with the exact two-line text "The word for fire in" then "the Ancient Language." Keep the "Fire." quote and "Ancient Language" subtitle. Do not introduce the phrase Dragon Language into Brisingr's card. Do not change spell spellings or reshape the header logo. This is a precise text correction, not a redesign.
