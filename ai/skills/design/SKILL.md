description: Create or extend versioned logo concepts and requested mockups inside a Library project, preserving prior rounds and leaving adoption to the user.
---

1. Read [Logo_Mockup_Guides.md](Logo_Mockup_Guides.md) before creating or extending logo concepts, visual identity rounds, or logo mockups. Resolve output paths relative to the requested project's root; use this Domains Database repository when no other project is named.

2. Follow the guide's project inspection, independent logo and mockup version series, editable artwork, and per-round documentation rules. Preserve earlier concepts and treat each version as a reviewable design round. Create mockups only when requested; change implementation assets or application code only when the user asks to adopt a concept.

3. Report the exact folders created. Follow the applicable project and Library instructions, leaving verification, testing, and builds to the user unless requested.
